# Навигация

---

Основным инструментом навигации приложения является библиотека `react-router-dom`,
для этого приложение обёрнуто в `BrowserRouter`.

Корневой роут приложения - `/`

При создании путей для страниц необходимо учитывать, что внутренние модули
наследуют пути внешних. 

Так, путь модуля [User](../src/Entry/Pages/UserPage/Path.ts) будет выглядеть как `/user`

Путь модуля [Payment](../src/Modules/User/Entry/Pages/PaymentPage/Path.ts) будет выглядеть как
`/user/payment`

Основным инструментом перехода по страницам приложения является хук 
__[useNavigateWithParams](../src/Entry/Hooks/Navigate.ts)__. Он позволяет сохранять `QueryParams`

Допускается использование нативного `useNavigate` вне модулей, где возможна потеря `QueryParams`

---

__Все параметры необходимо использовать только через RouteParams, например:
`payment/:stepId`__

__Все параметры RouteParams должны быть объявлены енамом для типизации__
