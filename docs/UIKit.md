# UI-Kit

---

Весь UI-Kit объявлен в [корневом модуле](./Structure/Module.md), в папке `Common/Components`

Представляет собой набор компонентов, необходимых для переиспользования из любого места приложения.

Каждый компонент должен быть описан максимально абстрактно
для возможности дальнейшего раширения его функционала. За исключением базовой потребности 
этого компонента 
__(
`Select` - нужен для выбора из списка, 
`Stepper` - нужен для отображения пройденного пользовательского пути,
`Loader` - нужен для показа процесса загрузки
)__, и т.д.

Допускается создание _Обёртки_ над компонентом для инкапсуляции, например: 

У каждой __Формы__ присутствует: 
* заголовок
* подзаголовок
* степпер
* кнопки контроля формы (отправка/возврат)

Нам нет необходимости создавать новую форму каждый раз только из-за того, 
что в ней присутствует разный контент. 
__Так была создана обёртка [FormWrap](../src/Common/Components/FormWrap/index.tsx)__
