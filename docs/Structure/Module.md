### Модули

---

Так, [корневая папка](../../src) является необъявленным основным модулем.
В ней соблюдается вся структура описанная [выше](../Structure/index.md).

Модули способны раскрываться далее на эти же сущности до
достижения конечной сущности. Так, например: [User](../../src/Modules/User)
является модулем первого уровня приложения. Внутри него существуют 
модули: ([Пополнение](../../src/Modules/User/Modules/Payment), 
[Инструкция](../../src/Modules/User/Modules/Connecting), 
[Баланс](../../src/Modules/User/Modules/Balance)) - они являются конечными модулями.


Внутри конечного модуля, такого как [Payment](../../src/Modules/User/Modules/Payment), в ней
хранятся только данные для использования этого модуля, такие как:
* Общий редьюсер данных этого модуля
* `index.tsx` файл модуля, в котором объявлен `export default`
* Хуки, компоненты, модели данных
