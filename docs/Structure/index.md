# Структура проекта

---

Проект делится на 3 сущности: (_Entry_, _Common_, _Modules_)
1. [__Entry__](./Entry.md) - Точка входа в модуль.
2. [__Common__](./Common.md) - Общие данные в рамках одного модуля.
3. [__Modules__](./Module.md) - Внутренние модули. 

В [корневом модуле](../../src) находится папка `Assets`, все статичные файлы:
* Шрифты
* Картинки (не векторная графика)
* и т.д.

должны находится в ней.
