### Common

---

__Общие данные модуля.__

Так, в [корневой папке](../../src) прокета в ней хранятся:
* Сервисы для взаимодействия клиент-сервер
* Общие модели, енамы например для `redux`
* Общие хэлперы, используемые из любой части проекта
* Весь [UIKit](../UIKit.md) проекта
* Общие текстовки, исползуемые из любой части проекта
* Общие константы
* **Namespace** для экшенов приложения

Внутри встраиваемого модуля, такого как [User](../../src/Modules/User), в ней хранятся:
* Утилиты, используемые только внутри этого модуля
* Компоненты, используемые только внутри этого модуля
* **Namespace** для экшенов модуля
